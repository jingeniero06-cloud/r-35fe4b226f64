Executive summary

A capable agency site held back by mobile speed and one bad canonical

The Mighty Mo! has a solid technical base — HTTPS, Rank Math sitemaps, rich homepage schema, and consistent Minneapolis NAP. The losses concentrate in three fixable areas.

  1. Mobile speed. Lab Performance 47 with LCP 6.9 s. Desktop is fine (92 / 1.6 s), so this is front-end weight, not hosting.
  2. Index hygiene. A primary WordPress design URL canonicalizes to the homepage, so Google may never rank that service page.
  3. AI / local completeness. No FAQPage or llms.txt; geo landings miss JSON-LD; GBP is absent from Organization sameAs.

Overall health score 72/100. The five high-priority fixes are mostly WordPress configuration and template changes.

Method

Full inventory of 289 Rank Math sitemap URLs from XML. Deep HTML parse on 7 money templates (title, meta, H1, canonical, JSON-LD). Specialist findings for technical, on-page, schema, local, performance, GEO/AEO, content, and visuals. Lighthouse 13.5 mobile on 5 templates; desktop baseline on the homepage. Cloudflare blocked bulk curl/Playwright re-crawls mid-session; Lighthouse Chromium and earlier HTML captures were used as the verified evidence set.

Not covered

Backlinks, rankings, Google Business Profile dashboard access, Search Console coverage, and real-user CrUX. Speed figures are lab measurements — confirm in Search Console Core Web Vitals when access is available.
